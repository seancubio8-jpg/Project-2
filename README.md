# SmartSip – Arduino Water Dispenser Website

## Files
- `index.html` – interactive browser simulator
- `style.css` – simulator styling
- `script.js` – simulator behavior
- `project-guide.html` – project overview, materials, suggested connections, construction steps, operation, and testing
- `guide.css` – documentation page styling
- `assets/smartsip-build-infographic.png` – illustrative project infographic

## Run
Extract the folder and open `index.html` in a modern browser. Use the “Build guide & materials” link to open the documentation.

## Important
The website is a front-end simulation only. It does not connect to physical Arduino hardware. The parts list and wiring plan in the guide describe a proposed physical prototype and must be checked against actual component datasheets and instructor/technician guidance before construction. Use a low-voltage DC pump supply, suitable driver/protection, food-safe wetted parts, and keep electronics dry and separated from water.
